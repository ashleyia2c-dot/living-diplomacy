# Lore profiles

One JSON file per legendary lord, named after the lord's agent subtype (`wh3_main_cth_miao_ying.json`).
The companion checks the lord's own file first and `<faction_key>.json` second, so a successor does
not inherit the previous ruler's voice. On first contact it copies the profile to
`data/campaigns/<campaign>/<faction>/leaders/<leader-subtype>.json`, but **the profile in this folder
takes precedence** over that copy, so lords met before a profile existed also receive it.

- `canonNotes`: facts about the character, summarised in our own words (never copy text from the
  game or from books).
- `voiceNotes`: speaking style, priorities and taboos.
- `temperament` (0-100): aggression, caution, pride, greed, honour. Replaces the values otherwise
  generated from the lord's name.
- `socialStyle` (0-100): warmth, sociability, generosity, vanity, spite, opportunism.
- `voiceGender`, `ttsInstructions`, `sources`.

The legendary lord profiles are generated by `scripts/lore/build_profiles.py` from
`scripts/lore/part1-3.py`; edit those and run it again. They summarise each lord's in-game unit
lore from Total War: WARHAMMER III and the Warhammer Fantasy background; lords from the newest DLC
rely only on the game's own text.
